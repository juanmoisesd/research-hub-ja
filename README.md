## Resumen del Repositorio
Este repositorio contiene datos y recursos relacionados con el **hub de investigación**. Es parte de una iniciativa de ciencia abierta para compartir hallazgos de investigación y conjuntos de datos con la comunidad científica global.

## Contexto de Investigación
El proyecto aborda preguntas clave en el campo de la neurociencia y las ciencias sociales, enfocándose en proporcionar datos accesibles para su posterior análisis y validación.

## Estructura del Repositorio
- `data/`: Contiene los conjuntos de datos utilizados en esta investigación.
- `src/`: Código fuente para el procesamiento y análisis de datos.
- `results/`: Archivos de salida, figuras y métricas.

## Uso
Para utilizar los recursos de este repositorio, clone el proyecto y asegúrese de tener instaladas las dependencias necesarias. Consulte la documentación específica en cada carpeta para más detalles.
